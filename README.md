# Hardware Specs Matcher

Hardware Specs Matcher / Can I Run It? is a small project for comparing a computer's hardware against the minimum or recommended requirements for a game or application.

## Overview

This project helps answer the question: "Can my current hardware run this program?"

It can be used to:
- compare CPU, GPU, RAM, and storage specs
- evaluate whether a system meets minimum or recommended requirements
- provide quick compatibility feedback for gaming or workstation workloads

## Features

- hardware specification matching
- minimum vs recommended requirement checks
- simple, clear output for performance compatibility
- easy extension for additional titles or workloads

## Project Goals

The goal of this project is to make hardware compatibility checks simple and understandable. Instead of manually comparing values, the app can surface whether a machine is likely capable of running a given workload.

## Typical Use

1. Input the target application's requirements
2. Enter or load the system's current specifications
3. Compare each category side-by-side
4. Review results and identify bottlenecks

## Tech Stack

This project is intended to be lightweight and approachable. It may be implemented with:
- HTML / CSS / JavaScript for a web interface
- Python or another backend language for matching logic
- JSON or structured data files for game or hardware configuration
